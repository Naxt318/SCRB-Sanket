# Deploying SCRB Sanket to Firebase

Just **Firebase Hosting** (static files) + **Firebase Authentication**
(login). No Cloud Functions, no backend server, no Blaze plan — this runs
entirely on the free **Spark** plan.

Everything the app used to ask a server for (FIR records, chat answers,
network graphs, trends, the audit log) is generated by synthetic data and
plain TypeScript logic that ships in the browser bundle instead — see
[`artifacts/scrb-sanket/src/local-api/`](./artifacts/scrb-sanket/src/local-api/).
Nothing here talks to a real crime database; it's a self-contained demo.

Login uses real Firebase Authentication (Email/Password provider). The
three demo accounts below aren't hardcoded passwords in the code — they're
actual accounts you create once in the Firebase console. Each account's
role/district/badge is looked up by email in
[`artifacts/scrb-sanket/src/lib/demo-users.ts`](./artifacts/scrb-sanket/src/lib/demo-users.ts)
(full profile in
[`artifacts/scrb-sanket/src/local-api/demo-profiles.ts`](./artifacts/scrb-sanket/src/local-api/demo-profiles.ts)).

## One-time setup

1. **Create a Firebase project** at https://console.firebase.google.com.
   The free **Spark** plan is all you need — you never have to switch to
   Blaze for this app.

2. **Enable Email/Password sign-in**: Firebase console → **Authentication**
   → Sign-in method → enable **Email/Password**.

3. **Create the three demo accounts**: Authentication → Users → Add user,
   for each row in the table above (exact email, password `scrb2024`).
   Want a fourth real account? Create it the same way, then add a matching
   entry to *both* `demo-users.ts` and `demo-profiles.ts` above.

4. **Get your web app config**: Project settings (gear icon) → General →
   scroll to "Your apps" → Add app → Web (`</>`) → register it (Hosting
   setup isn't needed here, you can skip that step) → copy the `firebaseConfig`
   object it shows you.

5. **Set up the `.env` file**:
   ```bash
   cp artifacts/scrb-sanket/.env.example artifacts/scrb-sanket/.env
   ```
   Paste the six values from step 4 into it:
   ```
   VITE_FIREBASE_API_KEY=...
   VITE_FIREBASE_AUTH_DOMAIN=...
   VITE_FIREBASE_PROJECT_ID=...
   VITE_FIREBASE_STORAGE_BUCKET=...
   VITE_FIREBASE_MESSAGING_SENDER_ID=...
   VITE_FIREBASE_APP_ID=...
   ```

6. **Install the Firebase CLI** (if you don't have it) and log in:
   ```bash
   npm install -g firebase-tools
   firebase login
   ```

7. **Set your project ID** in `.firebaserc` (repo root) — replace the
   placeholder with your actual Firebase project ID (top-left of the
   Firebase console, under the project name).

## Install & build

From the repo root:
```bash
pnpm install
pnpm --filter @workspace/scrb-sanket run build
```

## Deploy

```bash
firebase deploy --only hosting
```

Prints a live URL like `https://your-project-id.web.app` — open it and log
in with any of the three demo accounts.

## Local development

```bash
pnpm dev
```

Runs Vite against `artifacts/scrb-sanket/.env`. There's no separate API
server to start — `/api/*` calls are intercepted in the browser and
answered by `src/local-api/` directly (see
[`custom-fetch.ts`](./lib/api-client-react/src/custom-fetch.ts)'s
`setLocalHandler`), so this one command is the whole dev stack.

## Troubleshooting

- **Build fails with a JSON parse error on `package.json`** — the file
  being read has invalid JSON syntax (often from a manual edit in
  GitHub's web editor). Copy `package.json` from this fixed package over
  whatever's in your repo and re-push.
- **Login fails with "Firebase isn't configured"** — `.env` is missing or
  wasn't filled in; see step 5 above.
- **Login fails with "Invalid email or password"** — double check the
  account exists in Firebase console → Authentication → Users, and the
  email/password match exactly (including the `@scrb.demo` domain).
- **Logged in but immediately bounced back to the login page** — the
  signed-in email isn't in `demo-profiles.ts`, so the local `/auth/me`
  handler returns 401 and the frontend signs you back out. Add the email
  there (and to `demo-users.ts` for the login picker) and rebuild.
