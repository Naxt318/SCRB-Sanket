Build a working prototype called "SCRB Sanket" — an AI-powered conversational crime intelligence 
platform for the Karnataka State Crime Records Bureau (SCRB).

CONTEXT: Investigators across 1100+ Karnataka police stations currently rely on static dashboards. 
This platform lets them query crime data in natural language (English + Kannada) and surfaces 
patterns, criminal networks, hotspots, and predictive insights.

TECH STACK: React 18 + Vite + Tailwind CSS + Firebase (Auth + Firestore for session/query history) 
+ Recharts (trend charts) + react-force-graph or D3 (network visualization) + Leaflet (hotspot maps) 
+ Web Speech API (voice input/output) + Claude API (NL understanding + response generation) 
+ jsPDF (conversation export).

DATA: Since real SCRB/CCTNS data isn't accessible, generate a realistic SYNTHETIC dataset (clearly 
labeled as synthetic in the UI) covering: ~500 mock FIR-style records across 5-6 Karnataka districts, 
crime categories (theft, cybercrime, chain snatching, narcotics, etc.), timestamps, rough geo-coordinates, 
and anonymized "person of interest" linkage IDs for network analysis. Never use real names or real 
ongoing case references.

CORE FEATURES (build in this priority order):
1. Natural language chat interface — bilingual toggle (English/Kannada), answers questions like 
   "show me chain snatching cases in Bengaluru in the last 3 months" by querying the synthetic dataset 
   and returning a structured answer + supporting chart/map.
2. Context-aware conversation — follow-up questions ("now break that down by time of day") work 
   without restating context.
3. Crime hotspot map — Leaflet map with density/heat overlay by district, filterable by crime type and date range.
4. Criminal network visualization — force-directed graph showing linkage between mock persons-of-interest 
   across cases (co-accused, same MO, shared location), click a node to see connected case summaries.
5. Trend & predictive panel — simple time-series forecast (moving average is fine for a prototype) 
   flagging districts with rising crime-type trends as "early warning" cards.
6. Explainable AI / audit trail — every chatbot answer shows "Sources considered" and "Reasoning steps" 
   in a collapsible panel, plus a persistent query log for accountability.
7. Role-based access — a simple mock login (Investigator / Supervisor / Admin) that gates the audit 
   trail and network-analysis features to higher roles.
8. Voice input/output — mic button for query input, optional text-to-speech for responses.
9. PDF export — export the current conversation thread as a formatted PDF with a Karnataka Police 
   letterhead placeholder.

DESIGN DIRECTION: Official, trustworthy, command-center feel — not a consumer chat app. Deep navy/indigo 
base, maroon and gold accents (echoing the state emblem's palette), clean sans-serif for English, 
Noto Sans Kannada for Kannada text. Dashboard should feel like something a DGP would actually approve, 
not a hackathon toy.

CRITICAL DISCLAIMERS TO BUILD IN: 
- A persistent banner: "Demo environment — synthetic data only, no real case records."
- A "Data Privacy & DPDP Act 2023 Compliance" info panel explaining how a production version would 
  handle real crime data (encryption at rest, access logging, data minimization).

Build this iteratively: get the chat + synthetic data query working first, then layer in map, 
network graph, and the rest. Prioritize a smooth end-to-end demo flow over feature count.
